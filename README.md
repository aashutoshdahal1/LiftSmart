# LiftSmart

AI-powered fitness and nutrition coach PWA.

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Framer Motion · TanStack Router · TanStack Query · Redux Toolkit · React Hook Form · Zod · Recharts

## Development

Requires Node.js — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/aashutoshdahal1/LiftSmart.git
cd LiftSmart
npm i
npm run dev
```
